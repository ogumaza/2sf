2sf 0.1.0 is the first release of 2sf. 2sf rips the music of Nintendo DS games to 2SF, the PSF-family format for DS music. A set contains the game's cartridge image, cut down to what its music reads, and a small stub that starts one song. A 2SF player emulates the console and runs the game's sound code. The music then plays as it does in the game.

`2sfrip` runs on Windows 10 or later and requires no runtime DLLs. For macOS, the README explains how to build from source.

## Features

- **Ripping.** `2sfrip game.nds` recognises the game and writes a `.2sflib`, a `.mini2sf` for each song and a playlist. The library is named after the cartridge's product code, and each mini after its place in the set and its title. `--list` lists the songs, and `--only` rips the songs whose names match.
- **The stub.** The stub replaces the game's main loop. The game's start-up sets up the SDK, the file system and the sound as on the console. Then the stub loads the song whose number the mini stores with the game's loader, starts it, and runs the sound driver once a frame as the game does.
- **The library.** The library keeps the cartridge's header, both programs, the file system's tables and the files that the music reads. Every other file's bytes are zeros.
- **Lengths.** Each song's length comes from a walk of its song file: two passes of the loop and a fade of 10 s, or the end of a sound effect and a fade of 1 s. The time from the boot to the song's start, measured on a model of the DS, comes first.
- **Tags.** Each mini has its title, the game, the year, the copyright, the length and the fade, and `2sfby` where it's given. The library has no tags. The options `--game`, `--artist`, `--year`, `--copyright` and `--by` replace them.

## Beat City

`2sfrip` rips the US release (NTR-BEYE). Its music plays on Universomo's sound driver, a tracker in the game's ARM9 program. The set contains the game's 66 pieces of music: the long pieces, the menus' loops and every version of each mini-game's music. `--effects` adds the 81 sound effects. Song 105 is the title screen's music. The game gives its music no names. The other songs are named by their number.

The sets play in vio2sf, the 2SF component for foobar2000, with the loops that the song files give. vio2sf decodes them many times faster than real time. In melonDS, a set written as a cartridge image plays as the game does. No console has played the sets yet.

## Known limitations

- Only Beat City is supported. Games with the sound archives of Nintendo's SDK (SDAT) and other drivers will follow.
- The songs other than the title screen's are named by number.
- 2sf has no player in this release. A set requires a 2SF player that answers the cartridge's read commands from the image.
